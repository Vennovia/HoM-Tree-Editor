# Heart of Magic Tree Editor

The Heart of Magic (HoM) Tree Editor is a specialized visual tool for designing and managing spell structures. Create radial skill trees, manage prerequisite relationships, and export grimoires for use in any magic system.

## Key Features

- **Visual Node Editing**: Drag and drop spells in a radial or grid layout with coordinate snapping.
- **Arcane Connections**: Manage hierarchical relationships with support for hard and soft prerequisites.
- **Grimoire Management**: Import and export spell data in a standardized JSON format.
- **Responsive Canvas**: Pan, zoom, and multi-select tools built for large-scale magical datasets.
