# **App Name**: ArcanaFlow Studio

## Core Features:

- JSON Data Ingestion: Allow users to upload or paste spell tree JSON data for editing.
- Interactive Tree Visualization: Visually represent the spell schools and individual nodes as an interactive graph or tree structure.
- Node Property Editor: Display a detailed form to view and edit properties (name, formId, tier, skill level, theme, coordinates, locks, etc.) of a selected node.
- Node and Connection Management: Enable creation and deletion of nodes, and visually define relationships (children, prerequisites, hard/soft prereqs) between nodes using intuitive UI controls.
- AI-Powered Node Suggestions: Provide a tool to suggest creative names or themes for new nodes based on the selected spell school and existing node data.
- Export Edited Data: Allow users to export the modified spell tree data back into a valid JSON file.

## Style Guidelines:

- Primary Color: Deep Indigo (#3B2673) to convey a sense of arcane mystery and structured knowledge, reflecting the magical and data-centric nature of the application.
- Background Color: Dark Purple-Grey (#19161C), a desaturated variant of the primary hue, providing a quiet and immersive workspace reminiscent of a dark arcane study or night sky.
- Accent Color: Bright Medium Blue (#668CFF), an analogous hue to the primary, used to highlight interactive elements, selected nodes, and call-to-action buttons, offering a vibrant contrast for clarity and engagement.
- Primary Font: 'Inter' (sans-serif) for all text. Its modern, clean, and objective aesthetic ensures excellent readability and a professional feel for data presentation and editing forms.
- Utilize crisp, modern outline icons for all interface controls (e.g., add, delete, save, link), with filled variants for active states. Incorporate subtle magical glyphs or structured symbols for content categorization and node types where appropriate.
- Employ a three-panel layout: a collapsible left sidebar for global actions and navigation, a central canvas for the interactive spell tree visualization, and a right-hand detail panel for editing individual node properties. All panels should be resizable to optimize user workflow.
- Implement subtle, fast transitions (e.g., fades, slight enlargements) upon node selection, connection creation, and menu expansions/collapses to provide fluid feedback without hindering productivity. Active nodes and interactive elements should have a soft, pulsing glow accent.
